# 📝 Vite + React Task Manager

A sleek, lightweight, and responsive Task Manager built using React and modern CSS custom properties. This application supports task creation, completion toggles via checkboxes, deletion, and a real-time Light/Dark theme mode switch.

Updating new feature soon...

---

## ✨ Features

* **Task Management:** Add new tasks, mark them as completed using checkboxes, or delete them instantly.
* **Theme Switching:** Fully integrated **Light Mode** and **Dark Mode** toggle.
* **Modern UI:** Built using CSS variables (`:root`) for smooth theme transitions and a responsive layout.
* **Performance:** Powered by **Vite** for lightning-fast Hot Module Replacement (HMR) during development.
